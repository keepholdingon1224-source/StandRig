## 境界証拠と安全判定

元画像座標で、009-C境界の内外に顔幅に比例する帯を作った。front hair・顔との近さを頭部固定髪の支持、元画像の構造テンソルと既存中心線までの距離・方向を接続支持とした。原画と補完髪のRGB誤差、重ね順どおりのPSD再合成とのRGB誤差を分離計測した。結び目の位置は既存中心線の始点を引き継いだ。独立した装飾検出器は使っていない。衣装・背景との境界は候補として数え、所有者の再推定範囲はC2-Cの可視髪に限定した。pixel-evidence.jsonは帯内・変更画素別の色一致と接続性の集計。evidenceには方向別の局所許可マスクと摂動後マスクを保存した。

左右の面積変化は+1.16%～+1.73%。小ぼかしでの変更画素差は9～63画素。全体フォールバック0/2回、適用前後のIoU差は全項目0、これによって回避した退行は0件。局所許可後も素材1左の追加207画素中145画素がFPで、IoU低下を検知できなかった。一方で素材2左の追加715画素は全てTPだった。削除側の有効性は今回の実データでは確認できていない。

独立評価時に009-FのF3追加画素を凍結済み局所許可マスクに重ねると、素材1の過抽出6,162画素は全て許可外だった。素材2左では本当に回復した1,322画素のうち963画素も許可外となった。この事後診断には編集帯の外という理由で拒まれた画素も含む。誤抽出と正しい拡張を完全に識別したことは示していない。詳細はsafety-audit.json参照。

## 再現・保護

既存venvのCPUで integrity.py start、predict.py、独立evaluate.py、integrity.py end を実行。prediction-lock.jsonでコード・設定・入力・出力マスクと証拠を凍結し、評価時に再照合。IoUは1152×2048の全画素で算出した。手動座標指定、手動マスク修正、素材別設定、素材別後処理はすべて0件。005〜008と固定基準2,373件、009-Bローカル193件、009-Fまでの追跡記録638件は開始・終了のSHA-256が一致。ablations.csvは方式別の全数値、error-galleryはTP緑・FP赤・FN青。holdout-protocol.jsonに方式固定・復帰・別タスク実行の条件を記録した。

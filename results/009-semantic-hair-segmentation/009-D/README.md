# 実験009-D　毛束根元選択と接続帰属

**総合不合格、3/6項目合格。** 手動介入0回、素材別設定0回。009-Cは4/6で素材1全項目合格。事前指定したD正式方式では、素材1右が0.90を下回り、素材2右は正解との重なりが0になった。

## 条件と手順

固定009-C可視髪・スカート、009-B補完髪、原画像、保存済み009-C候補とグラフを使用。正解なしの事前診断は素材1/2で659/1,131ノード、18/36分岐点。双方とも1連結成分で仮想橋なし、可視髪上のノード率は80.7%/92.3%。端点・分岐・再接続はgraph-diagnostics.json。See-throughの再推論なし。公式fc4440dbに変更なし。CPU上の既存venvで実行、新しいモデル・パッケージ追加なし。

実装前に共通方式・定数・正式組み合わせをpreregistered-methods.txtとpreregistration.jsonに固定。予測後にprediction-lock.jsonで実コード・入力・全36枚のPNGを固定してから、別プロセスで原画座標・全画素を採点した。対照マスクは009-Cと画素一致。基準マスクや正解根元は予測側に渡していない。

- D1入力は候補ID・グラフ・半径・原画像・可視性、出力は選択ペア。根元の太さ変化とくびれを2倍、局所の流れ・方向・コントラスト・経路支持を各1倍で順位付け。対の幅比整合を有界加点。残り経路長と左右距離の加点は廃止。局所コントラストは装飾の弱い代理であり、リボンの検出ラベルは用いていない。スコアは確率ではない。
- D2入力は根元ペア・グラフ・原画像、出力は経路とノード帰属。Aは旧最短経路木、Bは色の不連続・局所方向・可視性・橋を費用化、CはA/Bとペナルティ付き再探索の候補を比較。探索記録はpath-comparison.json。
- D3入力はノード帰属・原画像・補完髪・固定可視髪、出力は排他的な左右毛束。固定・左・右のグラフ距離を比較し、原画エッジ、色、方向、可視境界に横断費用を付けた。局所半径による到達上限と固定側へのマージンを設けた。判定が弱い画素も固定側として採点。可視性の信頼性は固定済み二値可視支持とその境界を代理に使い、校正した連続確率は使っていない。

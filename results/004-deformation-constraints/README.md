## 固定条件とベースライン再現

003のコードを出力先だけ `work/003-reproduced` に変更し、物理計算から全240枚PNGまで再実行した。辺長比0.749552223966053〜1.2294404135205854、周期収束、面積、根元、ループ差、パーツ別可動範囲が保存済み003と一致。**240枚PNGすべてSHA-256一致**。003の成果物・コードは変更していない。

## 実装

**髪:** 旧Blend Shapeによる先端水平位置をそのまま目標とし、48回の二分探索で全長へ分散する曲率を求める。中心線の隣接行間距離は静止時と完全に同じ。横断方向は曲線の局所法線回転75%と元の向きの間でスキニングし、せん断を許す。根元の全頂点を保持。UVと画像は再生成・再サンプリングせず、元のStandRigテクスチャ描画を使用する。先端の水平運動は003と一致するが、縦運動・毛束輪郭・横断方向の回転は変わる。中心線長保持だけでは幅のある髪の全辺長を保証できず、今回も基準未達。

**裾:** 003 Blend Shape座標を目標に、各フレームで160回のPosition Based Dynamics距離投影を行う。全三角形辺で縦・横・対角せん断を拘束し、縦横2グリッド間のリンクを曲げ抵抗の近似とする。静止長の0.96〜1.04を拘束帯とし、毎反復0.002の目標座標への引力を入れる。これは**内部ソルバー設定**であり、合否判定の0.90〜1.10は変更していない。上辺の全頂点を固定。XPBDの動的布積分や厳密な二面角拘束ではなく、同じ物理入力に対する実験用の決定論的投影方式。拘束帯の切替と反復の残差により速度連続性は保証できず、実測も未達。

製品ソースは変更せず、StandRigのメッシュ評価・物理・描画を使う実験アダプターとして実装した。新方式のネイティブGUI/モーション再生への組み込みは未実装。`source-fixture.srig.json` 単体は003の元モデルで、004の再生結果は `geometry-trace.json` と生成コードで再構成する。別エンジンへの移行は行っていない。

## 途中の失敗と保存先

[初回方式](attempts/first/)は髪の局所曲率集中で辺長比0.224680〜1.775320、裾の静止長への強い投影で可動範囲36.029519pxとなり不合格。コード・数値・manifest・ワイヤーフレーム・ログを保持。髪の曲率を全長に分散し、先端xを003へ一致させ、断面回転を緩和した。裾は帯付き距離拘束へ変更した。入力振幅は変更していない。

最初の公式テストは、別worktreeで共有依存をsymlinkしたためzodの解決先が変わり、schema staleで失敗。[最初のログ](logs/npm-test.log)を保持。初回npm ciは既定のホーム配下cache書込み失敗で依存が揃わず、その後のbuild/testも失敗。ワークスペース内cacheを指定したnpm ci/build/testはすべて成功。製品schemaをテストのために書き換えてはいない。

初回独立検査では固定背景RGBの仮定がrendererの背景と違い全フレームを画面切れと誤判定した。[初回JSON](attempts/verification-first.json)と[ログ](logs/verify.log)を保存。003と同じく画像の背景画素を用いる検査へ修正し、全頂点座標の画面外判定も併用した。辺・面積・中心線・速度の測定定義と合格閾値は変更していない。

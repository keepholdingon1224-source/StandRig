# 実験009-B　See-through分離能力

前回の009-A改変構成を素材1・2に適用し、原画座標の凍結済みv4 PNGを使って自動分離の精度を測った。素材1はb4f136dの代表回1のPSDをハッシュ照合して再利用し、素材2は同じRTX 3060 Ti・NF4・1024・A3モデル単位転送で1回推論した。深度768、seed 42、LayerDiff 30ステップ、Marigold既定4ステップ。公式コードfc4440dbと重みは読み取りのみ。

## B1・B2　予測の固定

予測前のコード・規則・素材1のPSDのハッシュはpre-registration.jsonに収録。素材ごとの調整・手動介入は0回。補完部分を含む元のRGBAを保持したまま、PSDオフセットで元の位置に戻し、原画長辺の正方形へバイリニア補間して中央パディングを切り落とした。各画素は前面から最初にアルファ128以上となる層に帰属する。補完RGBAとこの可視マスクは別ディレクトリ。

front hairとback hairの和が意味上の髪、bottomwearはスカート候補。可視顔の下端以降に続く髪の8連結成分のうち、下端行に接し、顔の中心線の片側だけに収まる成分を画面左右の候補とした。残りの人物領域はfixed、未所有はbackground。headは頭部切り出し用の中間画像、tailは意味上の独立クラスで、いずれも左右毛束への読み替えには使わない。

## 毛束の失敗が生じた段階

素材1は髪の意味分類が正解毛束の98.86%を覆ったが、顔より下に続く固定髪も可動と判定し、左右とも過抽出。素材2左では正解68,549画素中、可視のfront/back hairは19,221画素。そのうち正式左毛束に残ったのは6,326画素。残る正解のうち48,328画素は補完済み髪には存在するが別の意味レイヤーに遮蔽され、1,000画素は補完髪にも存在しない。左毛束FNの可視所有者はtopwear 28,575画素、bottomwear 20,183画素。素材2右は正解27,094画素のうち24,935画素が可視髪になったが、根元32px窓内のIoUは左右とも0。意味レイヤーの可視順位と根元から束への対応の両方が精度を制限した。これらは評価専用の事後診断で、正式マスクには反映していない。[素材1](asset-01/hair-coverage.json)・[素材2](asset-02/hair-coverage.json)

両素材の予測を原PSDから再生成し、7種のマスクのSHA-256と予測記録が各素材で完全一致した。保護対象2,373ファイルは既存記録・開始時・終了時のすべてで一致。

## 009-Cへの申し送り

画面左右への帰属は自動化できても、顔下端は実際の可動根元を示さない。次段階には結び目・付け根の位置、どの束がそこにつながるか、束の中心線と前後の遮蔽、固定髪との境界を画像から推定する仕組みが必要。規則の見直しはこの2素材の正解に合わせず、別素材での検証を含める。正式評価の設定を一切変更せず、この結果を009-Bとして固定した。

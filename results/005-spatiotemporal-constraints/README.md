## 固定条件と実装

元の003素材・UV・153頂点/256三角形×2・8×16格子・物理駆動入力・60Hz収束トレース・パーツ変換・640×360カメラ・supersample1を保持。出力は8秒、30fps、240枚、真の最終サンプル時刻239/30秒。動画への8秒端点追加、先頭フレーム代入、クロスフェードは行っていない。比較のラベル以外は同一描画条件。

**髪：** 004の物理応答から得た中心先端変位をスカラー入力として用いる。16区間の中心線接線角、16断面の回転、縦方向伸び、幅の係数を同時に非線形最小二乗で求める。中心線は区間を積分、断面は局所回転・幅調整でスキニングする。全辺長、中心線長、先端範囲を同時に目的関数へ入れ、係数の空間2階差分も正則化。最適化用9振幅だけで合否を決めず、全482サンプル全辺・全三角形を後検査する。根元断面は完全固定。時間ごとの独立最適化や拘束のオン・オフは使わない。

先端水平位置は004と一致させない。髪の範囲は210.508→147.978px（約29.7%減）で、指定147pxを保持。基準を隠して動きを小さくしたのではなく、全辺拘束との競合を明示した応答変更である。ただし004の広い動きを維持した改善とは言わない。幅は最大約9.8%縮み、縦方向曲率が悪化するため次の改善課題。

**スカート（重点）：** 004の距離投影を空間ターゲットとして再現し、480サンプル周期全体の変位場へ時間方向σ=6サンプル（0.1秒）、裾に沿う格子方向σ=0.65列のGaussian正則化を適用。周期的な空間時間拡散によるオフラインのバッチ解法であり、全時間に同じ演算を適用する。境界だけを修正する処理ではない。空間平滑化は変位へ適用し、根元を固定する。布の距離・せん断・面積保持を004ターゲットから引き継ぎ、平滑化後に独立測定する。時間積分XPBDやオンラインの布シミュレータは実装していない。

揺れの時間倍率・入力振幅は変更せず、主要周波数は004/005とも0.125Hz。スカートの先端範囲67.081→66.800px（約0.42%減）、位相を合わせた比較を保持。既存の3段振り子に由来する縦方向の遅れは維持する。新たに裾方向へ慣性波を発生・伝播させる物理拘束は未実装であり、自然な波伝播の達成を数値だけで主張しない。

このソルバーは実験コードのみで動き、StandRigのネイティブGUI・リアルタイム再生には未統合。描画は既存StandRig software renderer。別エンジンへの全面移行は行っていない。

## 失敗した試行と未実施

[attempts.json](attempts.json)に髪先端151pxを狙う試行（辺長0.89789〜1.10127で未達）と、スカート時間/空間平滑化7条件を保存。σ=0の004は境界4.2747px/sで未達。σ=12は時間の平滑化が過大になる可能性を避け採用しない。選択σ=6は揺れ幅をほぼ維持し、余裕を持って境界を満たす。髪の試行コード断片は[attempts/](attempts/)に保存（初期scratchスナップショットであり、単独実行用の最終コードではない）。

初回独立検査は数値合格だが、入力fixtureの再JSON化で末尾改行が変わり、バイトハッシュ一致検査に失敗。素材・内容は同じでも成功扱いせず[初回検査](attempts/first-verification.json)と[初回ログ](attempts/first-independent-verification.log)を保存。元ファイルのバイトコピーに修正して最終検査を実行した。フォントキャッシュ警告は描画グラフ生成を阻害しなかった。初期の補助解析用scratchディレクトリ不足も修正後に再実行した。

ユーザーの005視覚審査、Windows実機、GUI統合、身体接続/衝突、布の裏面、全身制作、3D奥行きは未実施。裾方向の新たな物理波伝播や、任意素材に対する汎用自動リギングも未達。SONY共同プロジェクトの素材・コード・認証・サービスにはアクセスせず、main/原作者リポジトリには変更していない。

**総合不合格。4/6項目合格、手動介入0、素材別設定0。** 事前指定したC2-Cで素材1の3項目と素材2のスカートが0.90以上。009-Bの2/6という確定結果は別記録。素材3は使用していない。

候補は補完髪のalpha≥128による正解被覆率。可視性のみは補完髪に009-Bの接続規則を一度適用して左右の許容領域を固定し、その中の誤画素をすべて除ける楽観上限。接続のみは009-Bの可視髪を固定し、正解どおり左右へ割当てた上限。両方を与えたIoUは候補被覆率と数学的に一致する。素材2左の0は旧接続規則が補完髪上に左候補を作れなかった条件の値で、一般的な手法の上限ではない。素材2右の可視性のみ、素材2左の接続のみも0.90未満。両方を与えた上限は全項目0.90以上。

可視性を先に正解化して旧接続を再実行する補助診断では、左右IoUは素材1で0.4739/0.5930、素材2で0/0.6068。可動毛束の正解和のみを可視性に使い、固定領域にある髪の完全な正解がないため、その部分は旧可視モデルを保持した。Oracleマスクはoracle/に隔離した。実装前の投資判断は[investment.md](investment.md)。

## C1・C2

補完髪の距離変換・細線化から8近傍グラフを作成。頭部の太い部分から毛先への経路ごとに、局所のくびれ・向きの変化を用いて根元候補を順位付けし、異なる下流経路を2本選ぶ。選択根元につながる子孫枝をまとめて画素に戻し、根元のx座標順で左右を命名。顔下端や画面中央で髪を切断する操作は使わない。候補スコアは未校正。

C2-Aは前面優先、Bは髪と他層の前後を入れ替えた2通りの再合成を原画の色・局所輪郭と比較、Cは選択した枝に沿う前後の近傍証拠も使用。3方式とも同一の新C1を使用。方式・閾値・コードは[事前登録](preregistration.json)。補完髪は元のまま保持。真の遮蔽を全画素にわたり注釈した基準はなく、固定髪と非髪が混在する領域の可視性は未検証。

## 実行と証拠

入力PSD・中間レイヤーは009-Bのa30836aを再利用。See-throughの再推論なし。正本fc4440dbは無変更。既存venvで設定したCUDA_VISIBLE_DEVICESは3060 TiのUUIDのみ。C2画像整合性はPyTorchでRTX 3060 Ti上で実行し、C1グラフ、Oracle、独立採点はCPU上で実行。ライブラリ追加なし。005〜008・基準マスク2,373ファイルおよび009-Bの193ファイルを開始・終了時とも全件SHA-256照合。

予測プログラムの入力は原画像と009-Bの補完・可視レイヤーのみ。Oracleの正解画像や座標を読み込まない。predictions/asset-01、asset-02 に根元候補・グラフ・中心線、A/B/Cの原画解像度二値PNG、所有変更数、lock.jsonを保存。全予測を固定後に独立のevaluate.pyがハッシュ照合してuncertainを含む正式IoUを計算。[詳細指標](metrics.json)・[診断上限](oracle-diagnostics.json)。
